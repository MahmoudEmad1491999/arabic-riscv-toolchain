# The platform library `غرة.منصة` (decisions 58–59)

The tools written in غرة (Phase 6) touch the system only through this module. It is the غرة counterpart of `src/common/rt.h`. The module itself (`lib/غرة/منصة.غرة`) is plain غرة and the same everywhere; under it, a few **primitives** with raw names are written in assembly, once per back end:

| Back end | Primitives in | Built with |
|---|---|---|
| Linux (qemu-riscv64) | `lib/runtime/تشغيل.تجميع` (generated by `tools/gen_runtime.py`) | `مترجم` with `lib/` as search path |
| Our OS | `os/مستخدم/runtime/تشغيل.تجميع` (generated by the same script), on top of the `_نظام_` imports | `مترجم --برنامج` with `os/مستخدم` and `lib/` as search paths |

A program built for either back end therefore has the same غرة code; only the start file differs.

## The module

Names are assumption A76 (approved: the module name `منصة`).

| Member | Meaning | C counterpart |
|---|---|---|
| `ثابت المخرج: صحيح٢٣` / `ثابت الخطأ: صحيح٢٣` | standard output (1) and standard error (2) | `RT_STDOUT` / `RT_STDERR` |
| `دالة اكتب)ملف: صحيح٢٣، بيانات: ][ثابت طبيعي٨(` | write to standard output or standard error | `rt_write` |
| `دالة اخرج)رمز: صحيح٢٣(` | end the program with an exit code | `rt_exit` |
| `دالة اقرأ_ملف)س: ^ساحة، مسار: ][ثابت طبيعي٨، ناتج: ^][طبيعي٨(: منطقي` | read a whole file into memory from the arena | `rt_read_file` |
| `دالة اكتب_ملف)مسار: ][ثابت طبيعي٨، بيانات: ][ثابت طبيعي٨(: منطقي` | create or replace a file | `rt_write_file` |
| `دالة اجعل_تنفيذيا)مسار: ][ثابت طبيعي٨(: منطقي` | mark a file executable (Linux: mode 755; our OS: nothing to do) | `rt_make_executable` |
| `دالة أنشئ_أدلة)مسار: ][ثابت طبيعي٨(: منطقي` | create a directory and its missing parents | `rt_make_dirs` |
| `دالة متغير_بيئة)اسم: ][ثابت طبيعي٨، ناتج: ^][ثابت طبيعي٨(: منطقي` | an environment variable (our OS has none: always خطأ) | `rt_getenv` |
| `دالة احجز)مقدار: حجم(: حجم` | fresh zeroed memory straight from the system; ends the program with a message on failure | `rt_alloc` |
| `بنية ساحة` | an arena: a chain of blocks | `Arena` |
| `دالة ساحة_فارغة)(: ساحة` | an arena with no blocks yet | `arena_init` |
| `دالة احجز_في)س: ^ساحة، مقدار: حجم(: حجم` | the address of `مقدار` zeroed bytes, aligned to 8 | `arena_alloc` |
| `دالة بايتات_في)س: ^ساحة، مقدار: حجم(: ][طبيعي٨` | the same memory as a slice | `arena_alloc` |
| `دالة حرر_الساحة)س: ^ساحة(` | give back all of the arena's blocks at once | `arena_free` |

Program arguments are not here: `رئيسية` receives them (spec-language §7) on both back ends.

### Memory (decision 59)

- There is no `free` of a single allocation and no `realloc`. A growing buffer takes a new, bigger piece of its arena and copies (the C code's `rt_realloc` becomes this).
- An arena takes blocks of 1 MiB from `احجز` (a larger request gets a block of its own size). The block starts with a 24-byte header: the next block, the bytes used, the capacity.
- `حرر_الساحة` does not return memory to the system: its blocks go onto a free list inside the module, and the next arena that needs a block takes a big enough one from there first (zeroed again).
- An address from `احجز_في` is turned into a typed pointer with `اعتبر)^نوع، عنوان(`. `بايتات_في` makes its slice from a pointer to a very large array, which is the only way to make a slice from an address in غرة today.

### Paths

A path is passed to the primitives with a zero byte after it (the module copies it into a 4096-byte buffer; a longer path fails). The slice the primitives get does not include the zero.

## The primitives (raw names, `خارجي`)

| Primitive | Arguments → result | Linux | Our OS |
|---|---|---|---|
| `_غرة_اكتب` | file, bytes → count or negative | `write` | `_نظام_اكتب` (console, for 1 and 2) |
| `_غرة_اخرج` | code | `exit` | `_نظام_اخرج` |
| `_غرة_افتح` | path, mode (1 read, 2 write) → descriptor or negative | `openat` (write: create, truncate, mode 666) | `_نظام_افتح` |
| `_غرة_اقرأ` | descriptor, buffer → count, 0 at the end, negative on error | `read` | `_نظام_اقرأ` |
| `_غرة_اكتب_في` | descriptor, bytes → count or negative | `write` | `_نظام_اكتب_في` |
| `_غرة_أغلق` | descriptor → 0 or negative | `close` | `_نظام_أغلق` |
| `_غرة_اجعل_تنفيذيا` | path → 0 or negative | `fchmodat` 755 | 0 |
| `_غرة_أنشئ_دليل` | path → 0, or 1 if it already exists, or negative | `mkdirat` 777 (`EEXIST` gives 1) | `_نظام_أنشئ_دليل` |
| `_غرة_احجز` | size → address, or 0 | `mmap` anonymous, private, read/write | `_نظام_احجز` |
| `_غرة_البيئة` | → address of the environment pointer array | saved by `_بداية` | saved by `_بداية`: the empty list the kernel puts there |

`أنشئ_أدلة` treats "already exists" as success for every component, like `rt_make_dirs` (unlike it, it does not check that an existing name is a directory: the next file operation fails instead).

`os/برامج/تجربة_المنصة.غرة` runs the same checks as `tests/cc/منصة.غرة` on our OS (started by `أول` with two arguments).
